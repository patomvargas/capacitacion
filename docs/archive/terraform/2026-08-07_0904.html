Mejoras en Terraform

2026-08-07 0904 · Terraform

La extensión de Terraform para VSCode ha sido actualizada y ahora se integra con un nuevo servidor de lenguaje diseñado para crear una integración estable con Terraform a través de APIs públicas. Esto se logra mediante el comando `terraform init` y la configuración de la extensión en el archivo `settings.json`.

Un problema común con los módulos de Terraform es que el comando `terraform modules -json` devuelve la ruta de origen incorrecta para los módulos locales anidados. Esto se está solucionando en la issue #38872 del repositorio de Terraform en GitHub. Mientras tanto, se puede utilizar el comando `terraform state show` para obtener la ruta de origen correcta de los módulos.

En cuanto a la gestión de estados, Terraform ha incorporado mejoras en su sistema de workspaces. Ahora se puede utilizar el comando `terraform workspace` para crear y gestionar workspaces de manera más eficiente. Por ejemplo, se puede crear un nuevo workspace con el comando `terraform workspace new mi-workspace` y luego seleccionarlo con `terraform workspace select mi-workspace`.

Además, se han agregado nuevas características para mejorar la gestión de proveedores. Por ejemplo, se puede utilizar el comando `terraform provider` para instalar y configurar proveedores de manera más sencilla. También se ha agregado soporte para esperar a que el endpoint de SCM (Kudu) esté listo antes de la implementación en azurerm_linux_function_app.

En resumen, Terraform ha incorporado mejoras significativas en su extensión para VSCode, gestión de módulos y proveedores, y workspaces. Estas mejoras permiten a los desarrolladores y administradores de sistemas trabajar de manera más eficiente y segura con Terraform.

Finalmente, es importante mencionar que se han detectado vulnerabilidades de seguridad en algunas dependencias de Terraform, como la vulnerabilidad de bypass de características de seguridad en .NET. Es importante actualizar las dependencias y seguir las mejores prácticas de seguridad para evitar problemas.
