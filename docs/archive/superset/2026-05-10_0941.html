Superset: Administración y Mejoras

2026-05-10 0941 · Superset

Superset es una herramienta de código abierto desarrollada por Apache, que permite a los usuarios crear dashboards y visualizaciones de datos de manera sencilla y eficiente. Para instalar Superset, se puede utilizar el comando `docker run -p 8088:8088 apache/superset`.

Una de las últimas novedades en Superset es la corrección del error `mcp no such command` en la versión más reciente de Docker. Este error se solucionó mediante la actualización de la imagen de Docker a la versión más reciente.

Además, se han realizado mejoras en la administración de Superset, como la corrección del bug que impedía que los filtros reutilizaran la consulta de los conjuntos de datos virtuales. Esto se logró mediante la actualización de la configuración de `superset_config.py` y la ejecución del comando `superset db upgrade`.

Otra mejora importante es la corrección del error que ocultaba la etiqueta de fecha en el eje X de las gráficas de series temporales. Esto se solucionó mediante la actualización de la versión de Superset y la ejecución del comando `superset init`.

Para mejorar la seguridad de Superset, se recomienda utilizar la autenticación de Kerberos y configurar los permisos de acceso adecuados. También es importante mantener la versión de Superset actualizada para evitar vulnerabilidades de seguridad.

En cuanto a las mejores prácticas, se recomienda utilizar plantillas de Jinja para crear dashboards personalizados y aprovechar las funcionalidades de SQL Lab para crear consultas complejas. También es importante crear conjuntos de datos y gráficas de manera organizada y estructurada para facilitar la visualización y análisis de los datos.
