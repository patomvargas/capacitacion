BIND9: Mejoras y vulnerabilidades

2026-08-12 0915 · DNS BIND9

La versión 9.20.26 de BIND9 incluye varias correcciones de seguridad, incluyendo la vulnerabilidad CVE-2026-11605, que se refiere a la validación innecesaria de registros DNSSEC firmados. Para solucionar esta vulnerabilidad, se debe actualizar a la versión 9.20.26 o superior.

Para configurar DNSSEC en BIND9, se deben seguir varios pasos. En primer lugar, se debe generar una clave de zona utilizando el comando `dnssec-keygen`. Luego, se debe configurar la zona para utilizar DNSSEC mediante la directiva `dnssec-validation` en el archivo de configuración `named.conf`.

Además, se debe configurar el logging para monitorear el rendimiento y la seguridad del servidor DNS. Se puede utilizar la directiva `logging` en el archivo `named.conf` para configurar el logging. Por ejemplo, se puede utilizar la siguiente configuración: `logging { category security { security; }; };`.

La versión 9.20.26 de BIND9 también incluye mejoras en el rendimiento, incluyendo la optimización del uso de memoria y la reducción del tiempo de respuesta. Para aprovechar estas mejoras, se debe configurar el servidor DNS para utilizar las opciones de rendimiento recomendadas.

Finalmente, se debe mencionar que la configuración de vistas (views) y RPZ (Response Policy Zones) es fundamental para mejorar la seguridad y el rendimiento del servidor DNS. Se pueden utilizar las directivas `view` y `response-policy` en el archivo `named.conf` para configurar estas opciones.
