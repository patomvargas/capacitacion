MetalLB: Equilibrio de Carga en Kubernetes

2026-06-27 1013 · MetalLB

MetalLB es una herramienta esencial para cualquier clúster de Kubernetes que requiera exponer servicios a Internet. Para empezar a utilizar MetalLB, es necesario instalarlo en el clúster utilizando el comando `kubectl apply -f https://raw.githubusercontent.com/metallb/metallb/main/manifests/namespace.yaml`. Luego, se debe crear un pool de direcciones IP utilizando el comando `kubectl apply -f ip-pool.yaml`, donde el archivo `ip-pool.yaml` contiene la configuración del pool de direcciones IP.

En modo L2, MetalLB utiliza ARP (Address Resolution Protocol) para anunciar la dirección IP del servicio en la red local. Esto se logra configurando el archivo `metallb-config.yaml` con el contenido `address-pools: - name: default - protocol: layer2 - addresses: - 192.168.1.240-192.168.1.250`. Luego, se aplica la configuración utilizando el comando `kubectl apply -f metallb-config.yaml`.

En modo BGP, MetalLB utiliza el protocolo BGP (Border Gateway Protocol) para anunciar la dirección IP del servicio a los routers de la red. Esto se logra configurando el archivo `metallb-config.yaml` con el contenido `address-pools: - name: default - protocol: bgp - addresses: - 192.168.1.240-192.168.1.250 - bgp: - peer-address: 192.168.1.1 - peer-asn: 64512`. Luego, se aplica la configuración utilizando el comando `kubectl apply -f metallb-config.yaml`.

Para solucionar problemas con MetalLB, se puede utilizar el comando `kubectl logs -f -n metallb-system metallb-controller` para ver los registros del controlador de MetalLB. También se puede utilizar el comando `kubectl get pods -n metallb-system` para ver el estado de los pods de MetalLB.

En resumen, MetalLB es una herramienta poderosa para proporcionar equilibrio de carga en clústeres de Kubernetes. Su configuración es sencilla y flexible, y puede ser utilizada en modo L2 o BGP según las necesidades de la red.
