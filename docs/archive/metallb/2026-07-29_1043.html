MetalLB: Equilibrio de Carga en K8s

2026-07-29 1043 · MetalLB

MetalLB es un componente esencial en la infraestructura de K8s, ya que proporciona una forma de exponer servicios al exterior de la red. En modo L2, MetalLB asigna direcciones IP a los servicios utilizando el protocolo ARP. Para configurar MetalLB en modo L2, se debe crear un objeto `ConfigMap` con la configuración deseada, por ejemplo: `kubectl create configmap metallb-config --from-literal=config="{ "address-pools": [ { "protocol": "layer2", "addresses": [ "192.168.1.0/24" ] } ] }"`.

En modo BGP, MetalLB utiliza el protocolo BGP para anunciar las rutas a los servicios. Para configurar MetalLB en modo BGP, se debe crear un objeto `ConfigMap` con la configuración deseada, por ejemplo: `kubectl create configmap metallb-config --from-literal=config="{ "address-pools": [ { "protocol": "bgp", "addresses": [ "10.0.0.0/16" ], "bgp": { "peers": [ { "peer-address": "10.0.0.1", "peer-asn": 64512 } ] } } ] }"`.

La configuración de pools de IP es fundamental en MetalLB, ya que permite asignar direcciones IP a los servicios de manera eficiente. Para crear un pool de IP, se debe crear un objeto `ConfigMap` con la configuración deseada, por ejemplo: `kubectl create configmap metallb-config --from-literal=address-pools="[ { "protocol": "layer2", "addresses": [ "192.168.1.0/24" ] } ]"`.

En caso de problemas, es importante verificar la configuración de MetalLB y los logs de los componentes de K8s. Para solucionar problemas comunes, se pueden utilizar comandos como `kubectl get pods -n metallb-system` para verificar el estado de los pods de MetalLB, o `kubectl logs -f -n metallb-system ` para verificar los logs de un pod específico.

La integración con K8s es fundamental en MetalLB, ya que permite la asignación de direcciones IP a los servicios de manera automática. Para integrar MetalLB con K8s, se debe crear un objeto `Service` con la configuración deseada, por ejemplo: `kubectl create service loadbalancer --name=my-service --tcp=80:80`.
