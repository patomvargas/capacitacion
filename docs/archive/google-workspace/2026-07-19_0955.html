Novedades en Google Workspace

2026-07-19 0955 · Google Workspace

Google Workspace ha estado trabajando en mejorar la seguridad y la autenticación de sus usuarios. Recientemente, se ha introducido el soporte para claves de seguridad FIDO2 en el Google Credential Provider for Windows (GCPW), lo que permite a los usuarios utilizar claves de seguridad físicas como factor de autenticación adicional. Esto se puede configurar utilizando el comando `gcpw.exe /fido2` para habilitar el soporte para FIDO2.

La autenticación en Google Workspace se puede gestionar utilizando la consola de administración, donde se pueden configurar las políticas de autenticación y autorización para los usuarios. Por ejemplo, se puede utilizar el comando `gsuite authenticate` para autenticar a un usuario y obtener un token de acceso. Luego, se puede utilizar el comando `gsuite admin` para gestionar las políticas de autenticación y autorización.

Además de las mejoras en la autenticación, Google Workspace también ha introducido mejoras en la colaboración y la productividad. Por ejemplo, se ha introducido una nueva versión del Google Drive que permite a los usuarios compartir archivos y carpetas de manera más segura y eficiente. Se puede utilizar el comando `gdrive share` para compartir un archivo o carpeta con otros usuarios.

Otra novedad en Google Workspace es la introducción de la herramienta de búsqueda Gemini, que permite a los usuarios buscar y encontrar información de manera más eficiente. Se puede utilizar el comando `gemini search` para buscar información en Google Workspace. Esta herramienta es especialmente útil para los equipos de seguridad que necesitan buscar y analizar información de seguridad de manera rápida y eficiente.

En resumen, las novedades en Google Workspace buscan mejorar la seguridad, la colaboración y la productividad de los usuarios. Estas mejoras se pueden configurar y gestionar utilizando la consola de administración y los comandos de línea de comandos proporcionados por Google.

Es importante mencionar que la seguridad es un aspecto fundamental en Google Workspace, y se pueden utilizar herramientas como Google SecOps para mejorar la seguridad y la detección de amenazas. Se puede utilizar el comando `secops parse` para parsear los registros de seguridad y detectar posibles amenazas.
