Mejoras en Claude Code

2026-07-04 1015 · Claude Code

La última versión de Claude Code incluye varias mejoras y correcciones de errores. Una de las principales mejoras es la resolución del problema de conectividad que ocurría cuando se intentaba reconectar después de un error de autenticación. Esto se logró mediante la actualización del mecanismo de autenticación y la implementación de un nuevo sistema de gestión de tokens.

Otra característica importante es la adición de soporte para comandos de Git en segundo plano en Windows. Esto permite a los usuarios ejecutar comandos de Git sin tener que interactuar con la interfaz de usuario de Claude Code. Para habilitar esta característica, los usuarios deben configurar la variable de entorno `CLAUDE_CODE_GIT_COMMAND` con el comando de Git deseado.

Además, se han agregado nuevas características para mejorar la productividad y la experiencia del usuario. Una de ellas es la capacidad de configurar el comportamiento de la copia y el pegado en la ventana de Claude Code. Los usuarios pueden configurar la variable de entorno `CLAUDE_CODE_COPY_BEHAVIOR` para cambiar el comportamiento de la copia y el pegado.

Para aprovechar al máximo las nuevas características de Claude Code, los usuarios deben asegurarse de tener la última versión del software. También es importante consultar la documentación oficial para obtener más información sobre las nuevas características y cómo configurarlas. Por ejemplo, los usuarios pueden ejecutar el comando `claude-code --version` para verificar la versión actual del software.

Finalmente, es importante mencionar que Claude Code también ofrece una variedad de herramientas y extensiones para mejorar la productividad y la experiencia del usuario. Por ejemplo, la extensión de VS Code para Claude Code permite a los usuarios acceder a las características de Claude Code directamente desde la interfaz de usuario de VS Code.

En resumen, las últimas actualizaciones de Claude Code ofrecen una variedad de mejoras y nuevas características que buscan mejorar la productividad y la experiencia del usuario. Los usuarios deben asegurarse de tener la última versión del software y consultar la documentación oficial para obtener más información sobre las nuevas características y cómo configurarlas.
