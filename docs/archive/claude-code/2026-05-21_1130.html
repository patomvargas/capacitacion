2026-05-21 1130 · Claude Code

La integración de Claude Code con Visual Studio 2026 es una de las novedades más destacadas, lo que permite a los desarrolladores trabajar de manera más eficiente y efectiva. Para configurar esta integración, es necesario ejecutar el comando `claude code --vs-2026` en la terminal. Además, se han resuelto problemas con la caché de notas de lanzamiento, lo que garantiza que los usuarios tengan acceso a la información más actualizada.

Otra mejora importante es la resolución del problema con la caché de notas de lanzamiento, que se encontraba atascada en la versión 2.1.79 desde marzo de 2026. Para solucionar este problema, se puede ejecutar el comando `claude code --clear-cache` en la terminal. Esto garantiza que la caché se actualice correctamente y que los usuarios tengan acceso a la información más reciente.
