Novedades en ChatGPT

2026-08-13 0916 · ChatGPT

Recientemente, OpenAI ha publicado notas de lanzamiento para ChatGPT, API Platform y Codex. Estas notas destacan las últimas características, actualizaciones y mejoras en los productos de OpenAI. Una de las novedades más destacadas es la mejora del modelo GPT-5.6 Sol en ChatGPT, que ofrece una mayor precisión y coherencia en las respuestas.

Para acceder a estas mejoras, los usuarios pueden actualizar su versión de ChatGPT a la última disponible. Además, se ha expandido el acceso a GPT-5.6 Luna para usuarios gratuitos, lo que les permite disfrutar de conversaciones ilimitadas con este modelo avanzado.

En cuanto a las características de ChatGPT Voice, se ha implementado la función de voz en chat, que permite a los usuarios tener conversaciones naturales y en tiempo real con el modelo de lenguaje. Esta función se basa en GPT-Live y admite interrupciones, preguntas de seguimiento y capacidades como la búsqueda en la web. Para configurar ChatGPT Voice, los usuarios pueden seguir los pasos descritos en la documentación oficial de OpenAI, utilizando comandos como `chatgpt-voice --enable` para activar la función de voz.

Otra característica importante es la integración de ChatGPT con la API de OpenAI, que permite a los desarrolladores crear aplicaciones personalizadas que utilicen el modelo de lenguaje de ChatGPT. Para hacer uso de esta API, los desarrolladores pueden utilizar comandos como `openai-api --model chatgpt` para especificar el modelo de lenguaje que se utilizará.

En resumen, las últimas actualizaciones de ChatGPT ofrecen mejoras significativas en la precisión y coherencia de las respuestas, así como nuevas características como ChatGPT Voice y la integración con la API de OpenAI.

Para obtener más información sobre estas características y cómo configurarlas, se puede consultar la documentación oficial de OpenAI y las notas de lanzamiento de ChatGPT.
