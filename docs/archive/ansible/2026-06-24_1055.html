Ansible: Nuevas Características y Mejoras

2026-06-24 1055 · Ansible

La versión 14.0.0 de Ansible es la primera versión estable de Ansible 14 y depende de `ansible-core 2.21.0`. Esta versión incluye un conjunto curado de colecciones de Ansible que proporcionan una gran cantidad de módulos, plugins y roles.

Para empezar a trabajar con Ansible, es necesario instalar `ansible-core` y luego instalar las colecciones necesarias. Por ejemplo, para instalar la colección `ansible.posix`, se puede ejecutar el comando `ansible-galaxy collection install ansible.posix`.

Una de las características más destacadas de Ansible es la capacidad de crear playbooks y roles personalizados. Un playbook es un archivo que define una serie de tareas que se deben ejecutar en un conjunto de hosts. Un rol es un conjunto de tareas y handlers que se pueden reutilizar en diferentes playbooks.

Para crear un playbook, se puede utilizar el comando `ansible-playbook --help` para obtener información sobre las opciones disponibles. Por ejemplo, para ejecutar un playbook llamado `site.yml`, se puede utilizar el comando `ansible-playbook -i inventory site.yml`.

Ansible también proporciona una herramienta llamada `AWX` (Ansible Workstation) que permite gestionar y ejecutar playbooks de manera centralizada. `AWX` proporciona una interfaz web para crear y gestionar playbooks, así como para ejecutarlos en diferentes entornos.

En cuanto a la seguridad, Ansible proporciona una herramienta llamada `vault` que permite cifrar y descifrar datos sensibles, como contraseñas y claves SSH. Para utilizar `vault`, se puede ejecutar el comando `ansible-vault --help` para obtener información sobre las opciones disponibles.
