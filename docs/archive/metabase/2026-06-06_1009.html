Metabase 61: Gobernanza de IA y mejoras

2026-06-06 1009 · Metabase

Metabase 61 es la última versión del sistema de inteligencia empresarial y análisis de datos. Esta versión introduce una capa de gobernanza de IA que permite a los administradores controlar el acceso a los datos y a las herramientas de análisis. Se pueden establecer controles de acceso por grupo y límites de tokens para evitar el uso excesivo de los recursos.

Una de las características más destacadas de Metabase 61 es la personalización de Metabot, que permite a los usuarios crear sus propias herramientas de análisis y automatizar tareas. Para hacer esto, se puede utilizar el comando `metabot customize` para crear un nuevo modelo de Metabot. Luego, se puede utilizar el comando `metabot train` para entrenar el modelo con los datos de la empresa.

Además de la gobernanza de IA, Metabase 61 incluye mejoras en la administración y el análisis de datos. Se pueden crear dashboards personalizados con el comando `dashboard create` y se pueden agregar widgets con el comando `widget add`. También se pueden utilizar expresiones personalizadas para crear cálculos y análisis avanzados.

La versión 61 de Metabase también incluye mejoras en la API y en la integración con otras herramientas. Se puede utilizar el comando `api docs` para obtener información sobre la API de Metabase y se pueden utilizar los comandos `embed` y `unembed` para integrar Metabase con otras aplicaciones.

En resumen, Metabase 61 es una versión importante que introduce una capa de gobernanza de IA y mejoras en la administración y el análisis de datos. Los administradores y los usuarios pueden aprovechar estas características para crear herramientas de análisis personalizadas y automatizar tareas.
