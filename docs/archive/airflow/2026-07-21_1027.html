Airflow 3.3: Tareas con Estado y Soporte Multilenguaje

2026-07-21 1027 · Airflow

Apache Airflow 3.3 es una versión importante que introduce varias características nuevas y mejoras significativas. Una de las características más destacadas es el soporte para tareas con estado, lo que permite a los desarrolladores crear tareas que puedan mantener un estado interno y recuperarlo en caso de fallos. Esto se logra mediante el uso de un almacén de estado de tareas, que se puede configurar utilizando el comando `airflow db init` para inicializar la base de datos.

La versión 3.3 también incluye soporte multilenguaje, lo que permite a los desarrolladores escribir lógica de tareas en diferentes lenguajes de programación, como Java y Go. Esto se logra mediante el uso de un SDK de tareas que proporciona una API unificada para interactuar con Airflow, independientemente del lenguaje utilizado. Para utilizar este SDK, los desarrolladores pueden ejecutar el comando `airflow task-sdk` para generar un proyecto de tarea básico.

Otra característica importante de Airflow 3.3 es la mejora en la partición de activos, que permite a los desarrolladores dividir sus activos en particiones más pequeñas y gestionarlas de manera más eficiente. Esto se logra mediante el uso de un sistema de partición de activos que se puede configurar utilizando el comando `airflow assets partition` para crear y gestionar particiones. Además, la versión 3.3 incluye políticas de reintento configurables, lo que permite a los desarrolladores definir políticas de reintento personalizadas para sus tareas.

Para empezar a utilizar Airflow 3.3, los desarrolladores pueden ejecutar el comando `airflow upgrade` para actualizar su versión actual de Airflow a la versión 3.3. Luego, pueden crear un nuevo proyecto de Airflow utilizando el comando `airflow project init` y comenzar a definir sus flujos de trabajo y tareas utilizando la API de Airflow.

En resumen, Apache Airflow 3.3 es una versión poderosa y flexible que ofrece una amplia gama de características y mejoras para la orquestación de flujos de trabajo. Con su soporte para tareas con estado, soporte multilenguaje y mejoras en la partición de activos y políticas de reintento, Airflow 3.3 es una herramienta esencial para cualquier equipo de desarrollo que desee automatizar y gestionar sus flujos de trabajo de manera eficiente.
