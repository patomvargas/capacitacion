Apache Airflow 3.3: Tareas con Estado y Soporte Multilenguaje

2026-07-17 1002 · Airflow

Apache Airflow 3.3 es una versión importante que agrega funcionalidades clave para los desarrolladores de workflows. Una de las características más destacadas es el soporte para tareas con estado, lo que permite a los desarrolladores almacenar y recuperar datos entre ejecuciones de tareas. Para aprovechar esta característica, los desarrolladores pueden utilizar el `Language Task SDK` para escribir lógica de tareas en Java y Go.

La expansión de la partición de activos es otra característica importante en esta versión. Los activos se pueden particionar en función de diferentes criterios, lo que permite a los desarrolladores organizar y gestionar sus activos de manera más eficiente. Para configurar la partición de activos, los desarrolladores pueden utilizar el comando `airflow assets partition`.

Además, la versión 3.3 incluye políticas de reintento personalizables, lo que permite a los desarrolladores definir cómo se deben reintentar las tareas en caso de fallas. Para configurar las políticas de reintento, los desarrolladores pueden utilizar el comando `airflow config set retry_policy`.

La documentación de Airflow 3.3 también ha sido actualizada para reflejar las nuevas características y cambios. Los desarrolladores pueden encontrar más información sobre cómo utilizar las nuevas características en la documentación oficial de Airflow.

En resumen, Apache Airflow 3.3 es una versión importante que agrega funcionalidades clave para los desarrolladores de workflows. Con el soporte para tareas con estado, la expansión de la partición de activos y las políticas de reintento personalizables, los desarrolladores pueden crear workflows más complejos y eficientes.

Para empezar a utilizar Airflow 3.3, los desarrolladores pueden instalar la versión más reciente utilizando el comando `pip install apache-airflow` y luego configurar su entorno de desarrollo con `airflow db init` y `airflow users create`.
