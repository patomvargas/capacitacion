FreeIPA: Administración de Identidad

2026-07-11 0942 · FreeIPA

FreeIPA es un sistema de administración de identidad que se utiliza para proporcionar autenticación centralizada en entornos de Unix. Combina un directorio LDAP con un servidor Kerberos para proporcionar una solución completa de autenticación y autorización. Para implementar FreeIPA, es necesario configurar el servidor y los clientes para que utilicen el protocolo Kerberos para la autenticación.

La configuración de FreeIPA se puede realizar mediante la interfaz de línea de comandos `ipa` o mediante la interfaz web. Para agregar un cliente a FreeIPA, se puede utilizar el comando `ipa client-install` en el cliente y luego `ipa host-add` en el servidor para agregar el cliente al dominio. Luego, se puede configurar la autenticación Kerberos en el cliente con el comando `ipa getkeytab` para obtener el keytab del cliente.

Una de las características más importantes de FreeIPA es la capacidad de establecer relaciones de confianza entre dominios. Esto se puede hacer mediante el comando `ipa trust-add` para agregar un dominio de confianza. También se puede configurar el acceso basado en hosts (HBAC) para restringir el acceso a ciertos hosts o servicios. Para ello, se puede utilizar el comando `ipa hbacrule-add` para agregar una regla de acceso.

En cuanto a la autenticación, FreeIPA admite varios métodos, incluyendo la autenticación con contraseña y la autenticación con tarjeta inteligente. Sin embargo, en la versión actual, hay un problema con la autenticación con Passkey, como se indica en el issue #1130 de GitHub. Para solucionar este problema, se puede utilizar la autenticación con contraseña o configurar la autenticación con tarjeta inteligente.

Por último, es importante mencionar que FreeIPA tiene varias alternativas de código abierto, como se indica en la lista de Saasworthy. Sin embargo, FreeIPA sigue siendo una de las opciones más populares y ampliamente utilizadas para la administración de identidad en entornos de Unix.
