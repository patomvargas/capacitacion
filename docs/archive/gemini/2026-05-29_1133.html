Gemini: Nuevas Funcionalidades y Mejoras

2026-05-29 1133 · Gemini

La versión 3.5 de Gemini ofrece una serie de mejoras y nuevas funcionalidades, como la integración con Google Workspace y Vertex AI. Para empezar a utilizar Gemini, es necesario configurar el entorno de desarrollo con el comando `gemini init`. Luego, se puede crear un nuevo proyecto con `gemini create`.

Una de las novedades más destacadas de Gemini 3.5 es la introducción de la API de Gemini Live, que permite la creación de asistentes de voz avanzados. Para utilizar esta API, es necesario instalar el paquete `gemini-live` con el comando `pip install gemini-live`. Luego, se puede crear un nuevo asistente de voz con `gemini live create`.

La integración con Google Workspace es otra de las funcionalidades destacadas de Gemini 3.5. Para configurar la integración, es necesario seguir los pasos descritos en el artículo 'MCP Configuration for Google Workspace with Gemini CLI'. Esto incluye la creación de un nuevo proyecto en la consola de Google Cloud y la configuración de los permisos y credenciales necesarios.

La versión 3.5 de Gemini también ofrece mejoras en la seguridad y el gobierno de la plataforma. Para más información sobre estas mejoras, se puede consultar el artículo 'Tutorial Series: Gemini Enterprise Agent Platform — Part 4'. Este artículo presenta una guía detallada sobre cómo configurar y gestionar la seguridad y el gobierno en Gemini.

En resumen, Gemini 3.5 ofrece una serie de mejoras y nuevas funcionalidades que permiten a los desarrolladores crear aplicaciones de AI más avanzadas y seguras. Con la integración con Google Workspace y Vertex AI, los desarrolladores pueden crear aplicaciones más integrales y eficientes.

Para más información sobre Gemini y sus funcionalidades, se puede consultar la documentación oficial de la plataforma. Esto incluye la guía de inicio rápido, la documentación de la API y los tutoriales y ejemplos de código.
