Gemini: Avances y Mejoras en la API y Modelos

2026-07-28 1040 · Gemini

Gemini es un sistema de inteligencia artificial desarrollado por Google que ha experimentado recientes mejoras en su API y modelos. Una de las novedades más destacadas es la versión Gemini 3 Deep Think, que se enfoca en aplicaciones prácticas en ciencia, investigación y ingeniería. Para utilizar esta versión, se puede utilizar el comando `gemini-3-deep-think` en la API de Gemini.

La integración con Workspace y Vertex AI es otro aspecto importante de Gemini. Para conectar Gemini con Vertex AI, se puede utilizar el comando `gcloud ai vertex-ai endpoints create` y luego configurar el modelo de Gemini utilizando `gcloud ai vertex-ai models create`. Esto permite utilizar los modelos de Gemini en conjunto con las capacidades de Vertex AI.

En cuanto a la integración con Workspace, Gemini se puede utilizar para mejorar la productividad y la colaboración en equipo. Por ejemplo, se puede utilizar el comando `gemini-cloud-assist` para crear y ejecutar investigaciones en Gemini Cloud Assist. Sin embargo, es importante tener en cuenta que, a partir del 10 de abril de 2026, solo los usuarios con un contrato de soporte premium o que hayan solicitado acceso a través de su equipo de cuentas podrán crear, ejecutar y editar investigaciones en Gemini Cloud Assist.

Otra mejora importante es la unificación de las herramientas de Gemini Code Assist, que ahora están disponibles en una sola plataforma. Para utilizar Gemini Code Assist, se puede ejecutar el comando `gemini-code-assist` y seguir las instrucciones para configurar el entorno de desarrollo. Sin embargo, es importante tener en cuenta que, a partir del 18 de junio de 2026, Gemini Code Assist IDE Extensions y Gemini CLI dejarán de servir solicitudes para los usuarios individuales y los planes de Google AI Pro.

En resumen, Gemini es un sistema de inteligencia artificial que ha experimentado recientes mejoras en su API y modelos, y que se puede integrar con Workspace y Vertex AI para mejorar la productividad y la colaboración en equipo. Es importante estar al tanto de las novedades y cambios en la documentación oficial de Gemini para aprovechar al máximo sus capacidades.

Para más información, se pueden consultar las fuentes oficiales de Gemini, que incluyen la documentación de la API de Gemini, las notas de lanzamiento de Gemini y la documentación de Google Cloud. Estas fuentes proporcionan información detallada sobre las mejoras y novedades de Gemini, así como instrucciones para configurar y utilizar el sistema.
