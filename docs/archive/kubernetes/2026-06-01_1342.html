Novedades en Kubernetes v1.36

2026-06-01 1342 · Kubernetes

Kubernetes v1.36 es la última versión del sistema de orquestación de contenedores más popular del mundo. Esta versión incluye varias mejoras y nuevas características, como la graduación de características de DRA (Device Plugin Registration API) y mejoras en la usabilidad. Para actualizar a esta versión, se puede utilizar el comando `kubeadm upgrade apply v1.36.0`.

Una de las características más destacadas de esta versión es la mejora en la gestión de recursos. Ahora, es posible utilizar el comando `kubectl` para gestionar los recursos de forma más eficiente. Por ejemplo, se puede utilizar `kubectl get nodes` para obtener información sobre los nodos del clúster, o `kubectl describe node ` para obtener información detallada sobre un nodo específico.

En cuanto a la seguridad, Kubernetes v1.36 incluye varias mejoras, como la implementación de Network Policies para controlar el tráfico de red entre los pods. Esto se puede configurar utilizando el comando `kubectl create network-policy --pod-selector=`. Además, se puede utilizar el comando `kubectl get network-policies` para obtener información sobre las políticas de red configuradas.

Otra característica importante de esta versión es la mejora en el almacenamiento. Ahora, es posible utilizar el comando `kubectl` para gestionar los volúmenes de forma más eficiente. Por ejemplo, se puede utilizar `kubectl create persistent-volume --capacity=` para crear un volumen persistente, o `kubectl get persistent-volumes` para obtener información sobre los volúmenes configurados.

En resumen, Kubernetes v1.36 es una versión que incluye varias mejoras y nuevas características que pueden ayudar a los administradores de sistemas a gestionar sus clústeres de forma más eficiente. Es importante destacar que, para aprovechar al máximo estas características, es necesario tener una buena comprensión de la arquitectura y la configuración de Kubernetes.

Para más información sobre las características y la configuración de Kubernetes v1.36, se puede consultar la documentación oficial de Kubernetes. Además, se pueden utilizar herramientas como `kubeadm` y `kubectl` para gestionar y configurar los clústeres de Kubernetes.
