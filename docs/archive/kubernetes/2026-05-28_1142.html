Novedades en Kubernetes v1.36

2026-05-28 1142 · Kubernetes

La versión v1.36 de Kubernetes incluye varias novedades importantes, como el escalado vertical en lugar para recursos de nivel de pod, que permite ajustar los recursos asignados a un pod sin tener que reiniciar el pod. Esto se logra mediante el comando `kubectl scale` con la opción `--resource`.

Además, se introduce la característica de administradores de recursos de nivel de pod, que permite una gestión más flexible y poderosa de los recursos en los pods. Esta característica se encuentra en versión alpha y se puede habilitar mediante la opción `--feature-gates` en el comando `kubectl`.

Otra característica importante es la compatibilidad con GPU en los nodos de Kubernetes, lo que permite ejecutar cargas de trabajo de aprendizaje automático y alto rendimiento en los clústeres de Kubernetes. Para aprovechar esta característica, se pueden crear nodos dedicados para GPU mediante el comando `kubectl create node` con la opción `--gpu`.

La seguridad también es un aspecto importante en esta versión, con mejoras en la autenticación y autorización de los usuarios y servicios en el clúster. Se pueden configurar políticas de seguridad mediante el comando `kubectl create policy` con la opción `--security`.

En cuanto a la configuración y administración de los clústeres de Kubernetes, se pueden utilizar herramientas como `kubeadm` para crear y administrar clústeres de manera sencilla y segura. El comando `kubeadm init` se utiliza para inicializar un clúster de Kubernetes, mientras que el comando `kubeadm join` se utiliza para unir nodos a un clúster existente.

En resumen, la versión v1.36 de Kubernetes ofrece varias novedades y mejoras importantes para la gestión de recursos, la escalabilidad y la seguridad en los clústeres de Kubernetes. Estas características pueden ser aprovechadas mediante comandos y configuraciones específicas, como las mencionadas anteriormente.

Para obtener más información sobre las novedades y características de Kubernetes v1.36, se pueden consultar las fuentes oficiales de Kubernetes y los artículos de la comunidad de desarrolladores de Kubernetes.
