Novedades en Kubernetes 1.34 y 1.35

2026-06-29 1238 · Kubernetes

Kubernetes es un sistema de orquestación de contenedores que ha ganado popularidad en los últimos años debido a su escalabilidad y flexibilidad. Recientemente, se han lanzado las versiones 1.34 y 1.35, que incluyen varias mejoras y nuevas características. Una de las novedades más destacadas es la mejora en la gestión de volúmenes, que permite a los administradores de clusters gestionar de manera más eficiente los recursos de almacenamiento.

La versión 1.34 incluye una nueva característica llamada `CSI` (Container Storage Interface), que permite a los proveedores de almacenamiento crear drivers personalizados para interactuar con el sistema de orquestación. Esto permite una mayor flexibilidad y escalabilidad en la gestión de volúmenes. Por ejemplo, se puede utilizar el comando `kubectl` para crear un volumen persistente con el siguiente comando: `kubectl create -f persistent-volume.yaml`.

Otra novedad importante es la mejora en la autenticación de usuarios, que incluye la implementación de `OIDC` (OpenID Connect) para la autenticación de usuarios. Esto permite a los administradores de clusters configurar la autenticación de usuarios de manera más segura y escalable. Se puede configurar la autenticación de usuarios con el siguiente comando: `kubectl create -f oidc-config.yaml`.

Además, la versión 1.35 incluye mejoras en la gestión de redes, que permiten a los administradores de clusters gestionar de manera más eficiente los recursos de red. Se puede utilizar el comando `kubectl` para crear un servicio de red con el siguiente comando: `kubectl create -f network-service.yaml`.

En resumen, las versiones 1.34 y 1.35 de Kubernetes incluyen varias mejoras y nuevas características que permiten a los administradores de clusters gestionar de manera más eficiente los recursos de almacenamiento, autenticación de usuarios y redes.

Para obtener más información sobre las nuevas características y mejoras de Kubernetes, se puede consultar la documentación oficial en la página web de Kubernetes.

Se puede utilizar el siguiente comando para verificar la versión de Kubernetes: `kubectl version`.

Se puede utilizar el siguiente comando para obtener información sobre los nodos del cluster: `kubectl get nodes`.
