Novedades en Kubernetes v1.36

2026-05-16 0945 · Kubernetes

La versión v1.36 de Kubernetes es una de las últimas actualizaciones del sistema de orquestación de contenedores más popular. Una de las características más destacadas de esta versión es la activación de los espacios de nombres de usuario en Linux, lo que permite una mayor seguridad y aislamiento en los entornos de producción. Para aprovechar esta característica, se puede utilizar el comando `kubectl` con la opción `--userns-mode` para especificar el modo de espacios de nombres de usuario.

La seguridad es otro área en la que se han realizado mejoras en esta versión. Se han agregado nuevas características para proteger los clústeres de Kubernetes contra ataques y vulnerabilidades. Por ejemplo, se puede utilizar la herramienta `kustomize` para personalizar las configuraciones de seguridad de los clústeres. Para instalar `kustomize`, se puede utilizar el comando `go install kustomize`.

En cuanto a almacenamiento, la versión v1.36 de Kubernetes incluye mejoras en la gestión de volúmenes y almacenamiento persistente. Se puede utilizar el comando `kubectl` con la opción `--storage-class` para especificar la clase de almacenamiento para un volumen. Por ejemplo, `kubectl create -f persistent-volume.yaml --storage-class=gp2`.

La red es otro área en la que se han realizado mejoras en esta versión. Se han agregado nuevas características para mejorar la conectividad y el rendimiento de las redes en los clústeres de Kubernetes. Por ejemplo, se puede utilizar el comando `kubectl` con la opción `--network-policy` para especificar la política de red para un pod.

En resumen, la versión v1.36 de Kubernetes es una actualización importante que incluye mejoras en áreas como seguridad, almacenamiento y redes. Los administradores de sistemas y desarrolladores pueden aprovechar estas características para mejorar la seguridad, el rendimiento y la escalabilidad de sus clústeres de Kubernetes.

Para más información sobre la versión v1.36 de Kubernetes, se puede consultar la documentación oficial en el sitio web de Kubernetes. También se pueden encontrar tutoriales y ejemplos de código en sitios web como GitHub y Medium.
