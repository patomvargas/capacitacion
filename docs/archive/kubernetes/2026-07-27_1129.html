Novedades en Kubernetes 1.36

2026-07-27 1129 · Kubernetes

Kubernetes 1.36 es la última versión del popular sistema de orquestación de contenedores. Una de las novedades más destacadas es la mejora en el soporte para redes de alta disponibilidad. Para configurar una red de alta disponibilidad, podemos utilizar el comando `kubectl create deployment` con la opción `--replicas` para especificar el número de réplicas de nuestro deployment.

La seguridad es otro aspecto que ha sido mejorado en Kubernetes 1.36. Ahora, podemos utilizar el comando `kubectl create secret` para crear secretos cifrados que solo pueden ser descifrados por el controlador de secretos. Por ejemplo, podemos crear un secreto cifrado con el comando `kubectl create secret generic mysecret --from-literal=password=mypassword`.

En cuanto al almacenamiento, Kubernetes 1.36 soporta ahora el almacenamiento de objetos S3-compatible. Podemos utilizar el comando `kubectl create storageclass` para crear una clase de almacenamiento que utilice un proveedor de almacenamiento de objetos como Alarik. Por ejemplo, podemos crear una clase de almacenamiento con el comando `kubectl create storageclass mystorageclass --provisioner=alarik.io/alarik`.

Otra novedad interesante es la integración con el operador de Apache Flink, que nos permite gestionar aplicaciones de procesamiento de datos en tiempo real de manera más eficiente. Podemos utilizar el comando `kubectl create deployment` con la opción `--image` para especificar la imagen de Apache Flink que queremos utilizar.

Finalmente, es importante mencionar que la versión 1.36 de Kubernetes también incluye mejoras en la herramienta de línea de comandos `kubectl`. Ahora, podemos utilizar el comando `kubectl debug` para depurar nuestros pods y deployments de manera más eficiente. Por ejemplo, podemos utilizar el comando `kubectl debug mypod --container=mycontainer` para depurar un contenedor específico dentro de un pod.

En resumen, Kubernetes 1.36 es una versión muy completa que incluye mejoras en networking, almacenamiento, seguridad y herramientas de línea de comandos. Es importante estar al tanto de estas novedades para aprovechar al máximo las capacidades de Kubernetes en nuestros entornos de producción.
