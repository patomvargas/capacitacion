Novedades en OpenShift 4.22

2026-07-28 1040 · OpenShift

La versión 4.22 de OpenShift se basa en Kubernetes 1.35 y CRI-O 1.35, y ofrece varias mejoras y nuevas características para desarrolladores y administradores de sistemas. Una de las novedades más destacadas es la inclusión de Red Hat OpenShift Dev Spaces, que permite a los desarrolladores crear entornos de desarrollo personalizados y colaborativos.

La seguridad es otro aspecto importante en esta versión, con actualizaciones que incluyen la corrección de vulnerabilidades críticas. Para verificar la disponibilidad de actualizaciones, se puede utilizar el comando `oc adm upgrade` en la línea de comandos. Además, se puede utilizar el comando `oc get clusteroperators` para verificar el estado de los operadores del clúster.

En cuanto a la observabilidad, OpenShift 4.22 incluye la versión 1.5 del operador de observabilidad de clúster (COO), que ofrece dashboards personalizables y compatibilidad con fuentes de datos de monitoreo existentes. Para instalar el operador de observabilidad, se puede utilizar el comando `oc apply -f https://raw.githubusercontent.com/red-hat-storage/ocs-operator/main/deploy/csv-templates/crds/ocs/ocs.openshift.io_storageclusters.yaml`.

La migración a OpenShift 4.22 también es un proceso importante, y se puede realizar utilizando el comando `oc adm migrate`. Es importante tener en cuenta que antes de realizar la migración, se deben realizar copias de seguridad de los datos y configuraciones importantes.

En resumen, OpenShift 4.22 es una versión que ofrece muchas mejoras y nuevas características para desarrolladores y administradores de sistemas, y es importante estar al tanto de las novedades y cambios para aprovechar al máximo sus funcionalidades.

Para más información, se pueden consultar las fuentes oficiales de Red Hat y la documentación de OpenShift.
