OpenShift: Mejoras y Novedades

2026-08-13 0916 · OpenShift

La última versión de OpenShift Logging, la 6.5, incluye mejoras en la seguridad y el rendimiento. Para instalar esta versión, se puede utilizar el comando `oc apply -f https://raw.githubusercontent.com/openshift/cluster-logging-operator/master/templates/clusterlogging.crd.yaml`. Luego, se puede crear un objeto de configuración de logging con `oc create -f https://raw.githubusercontent.com/openshift/cluster-logging-operator/master/templates/clusterlogging.yaml`.

Otra novedad importante es la introducción de Red Hat Enterprise Linux CoreOS 10 en OpenShift 4.22. Esto permitirá a los clusters ejecutar diferentes flujos de CoreOS en el futuro. Para probar esta función, se puede crear un cluster de OpenShift con `oc cluster up --image=registry.redhat.io/openshift4/ose-coreos:4.22`.

En cuanto a la seguridad, es importante mencionar que se puede enriquecer los resultados de cumplimiento de OpenShift con metadatos personalizados. Para hacer esto, se puede crear un objeto ScanSettingBinding con `oc create -f https://raw.githubusercontent.com/openshift/compliance-operator/master/templates/scansettingbinding.yaml`. Luego, se puede agregar metadatos personalizados a los objetos ComplianceCheckResult con `oc annotate compliancecheckresult compliance.openshift.io/custom-metadata=`.

Además, se puede utilizar el OperatorHub para instalar operadores personalizados en OpenShift. Por ejemplo, se puede instalar el operador de AMD GPU con `oc create -f https://raw.githubusercontent.com/ROCm/gpu-operator/master/deploy/crds/gpuoperator.crd.yaml`. Luego, se puede crear un objeto de configuración de GPU con `oc create -f https://raw.githubusercontent.com/ROCm/gpu-operator/master/deploy/crds/gpuoperator.yaml`.

En resumen, OpenShift es una plataforma en constante evolución, y es importante estar al tanto de las últimas novedades y mejoras para aprovechar al máximo su potencial.

Finalmente, es importante mencionar que la documentación oficial de OpenShift es una excelente fuente de información para aprender sobre la plataforma y sus funcionalidades. Se puede encontrar documentación detallada sobre la instalación, configuración y administración de OpenShift en la página oficial de Red Hat.
